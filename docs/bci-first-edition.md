主线为 18 章＋术语附录。当前改稿按 [零基础阅读目标](../GOAL.md) 重写首页、全部主线正文、标题、摘要、自测和术语表，先解释现象，再引入名称；研究方法与原始出处可在章末展开。交互说明采用同样的顺序。

三维电极图谱和真实 EEG 观察器保留原数据与计算。第四、五章使用合成试次实验和 15 张 ERP 卡片，图示明确标明性质。第六至十八章有具体例子、解释、原始研究入口和自测，尚未逐任务内嵌真实数据或实现在线实验。

临床内容在主线只有第十七章。九个旧页面原文、图片和网址保留，但不出现在主目录、侧栏和上下章导航；页面顶端显示旧版未复核提示及对应新章链接。正常睡眠归入状态章，伪迹归入实验章，不因收拢临床而删去。

## 本地与 CI
沿 README 安装既有 Node/Python 依赖后：
```
npm run check
npm run build:pages
node scripts/test-bci.mjs
python -m pip install playwright==1.55.0
python -m playwright install chromium
python scripts/build-bci-preview.py
python scripts/test-bci-browser.py
```

浏览器检查也支持设置 `CHROMIUM_EXECUTABLE` 使用已有 Chromium。若受管浏览器禁止 `file://`，可设 `BCI_PREVIEW_TRANSPORT=http`：同一份独立预览由测试服务器提供，并检查没有加载额外网络资源；结果注明传输方式，不能据此声称已验证本地文件直接打开。前三章已纳入全部 18 章共有的结构检查；旧版要求正文逐字不变的哈希断言已随重写目标移除，依赖完整性和数值断言保留。零基础理解仍需 GOAL.md 中的真人试读。

工作流权限只读，不部署、不修改仓库。原有图谱与第三章检查照常运行。离线预览来自实际构建，含全部章节的本地导航、内嵌脚本和图片；文献外链需要网络。不要把预览文件中的路径当成已经上线的新页面。

## 教学与技术边界
合成平均固定正向上、µV 量纲为人为设定，固定随机种子；取前 n 条后才排除已知伪迹。无有效 A 试次时不显示 A 平均与 A−B，并明确显示原因。零输入不冒充缺失条件的均值。ERP 形态使用任意单位，只说明命名、对照和时间关系；没有虚构头皮热图、个体差异和单试次识别结果。

在后续真实数据版中，优先核对 ERP CORE 的协议和许可，并与其条件平均、差异波和试次数逐项对照。SSVEP／cVEP 页面本版不播放实际闪烁刺激；听觉页不播放强声。需要人体刺激时走独立的伦理、硬件时序和安全验证。

本次不更改依赖版本或 lockfile，不处理已有依赖安全告警；测试通过也不等于完整安全审计。内容变更进入独立 PR，用户审阅前不合并主分支。
