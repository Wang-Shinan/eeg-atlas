# BCI 教材第一版：编辑范围与验证

主线为 18 章＋术语附录。前三章正文和交互保持原样。第四、五章是新增合成教学实验：事件锁定／试次数／基线／潜伏期抖动／已知伪迹排除，以及 15 类 ERP 卡片和参数化形态。没有把这些图说成 ERP CORE 或其他人体实验数据。第六至十八章均有任务定义、实验对照、分析或评测入口、解释边界、原始研究来源和自测；此版本尚未为每一种任务内嵌真实数据或实现在线实验。

临床内容在主线只有第十七章。九个旧页面原文、图片和网址保留，但不出现在主目录、侧栏和上下章导航；页面顶端显示旧版未复核提示及对应新章链接。正常睡眠归入状态章，伪迹归入实验章，不因收拢临床而删去。

## 关键文件
- `src/data/legacy-chapters.ts`：旧网址到当前入口的映射。
- `src/lib/chapters.ts`：公开路由仍包括旧页，主目录只列当前内容；编号按专题显示。
- `src/lib/bci/epochs.ts`：纯函数的确定性合成数据和平均计算。
- `src/components/EpochLab.astro` / `ERPAtlas.astro`：不新增框架或依赖的交互。
- `src/data/erp-components.ts`：范式、零点、对照、空间／时间观察、边界和研究来源。绘图参数是本站构造，非规范测量值。

## 本地与 CI
沿 README 安装既有 Node/Python 依赖后：
```
npm run check
npm run build:pages
node scripts/test-bci.mjs
python -m playwright install chromium
python scripts/build-bci-preview.py
python scripts/test-bci-browser.py
```

新工作流权限只读，不部署、不修改仓库。原有图谱与第三章检查照常运行。离线预览来自实际构建，含全部章节的本地导航、内嵌脚本和图片；文献外链需要网络。不要把预览文件中的路径当成已经上线的新页面。

## 教学与技术边界
合成平均固定正向上、µV 量纲为人为设定，固定随机种子；取前 n 条后才排除已知伪迹。无有效 A 试次时不显示 A 平均与 A−B，并明确显示原因。零输入不冒充缺失条件的均值。ERP 形态使用任意单位，只说明命名、对照和时间关系；没有虚构头皮热图、个体差异和单试次识别结果。

在后续真实数据版中，优先核对 ERP CORE 的协议和许可，并与其条件平均、差异波和试次数逐项对照。SSVEP／cVEP 页面本版不播放实际闪烁刺激；听觉页不播放强声。需要人体刺激时走独立的伦理、硬件时序和安全验证。

本次不更改依赖版本或 lockfile，不处理已有依赖安全告警；测试通过也不等于完整安全审计。内容变更进入独立 PR，用户审阅前不合并主分支。
