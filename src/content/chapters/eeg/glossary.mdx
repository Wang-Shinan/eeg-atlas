这份速查表用来帮你把名称接回例子。可以先顺着主线读，遇到忘记的词再回来；每组都有返回解释的入口。

## 记录是怎样来的

| 词 | 用已经熟悉的事情理解 |
|---|---|
| 脑电 / EEG | 仪器把头皮不同位置之间的微弱电压差，随时间记录下来。 |
| 神经元 | 神经细胞的名称；它们参与看、听、记忆、行动等过程。 |
| 离子 | 带电的微小颗粒；它们的移动参与形成细胞中的电流。 |
| 电极 | 与头皮接触、帮助仪器接收电变化的小部件。 |
| 通道 | 一条比较记录，例如 O1 相对某个参考的电压变化。 |
| 参考 | 测电压时选的比较对象，可以来自一个位置或多个位置的组合。 |
| 微伏 / µV | 很小的电压单位；一微伏等于百万分之一伏。 |

## 位置与曲线怎样读

| 词 | 用已经熟悉的事情理解 |
|---|---|
| 10–20 系统 | 按头部测量距离的比例安排电极的一套规则。 |
| 模板坐标 | 标准头模上的位置，好比展示帽子用的头模。 |
| 导联 | 安排哪些电极电位互相比较、组成记录的方式。 |
| 频率 / Hz | 起伏有多快；10 Hz 表示一秒完成约 10 周。 |
| 振幅 | 电压起伏的大小，需要说明怎样量。 |
| 峰峰值 | 所选片段里最高与最低数值的差。 |
| 频谱 | 把一段记录中不同快慢的成分分开看。 |
| 频带功率 | 用指定快慢范围内的变化计算强弱的一种统计量。 |
| 时频图 | 继续看某种快慢的起伏在什么时候明显。 |
| 头皮图与插值 | 把通道数值放回位置，再估计点与点之间的颜色。 |

## 实验怎样把事情放在一起比较

| 词 | 用已经熟悉的事情理解 |
|---|---|
| 事件 | 一件有时间可记的事，如声音出现、手按键。 |
| 试次 | 实验的一轮，如听声音、回应、等待下一轮。 |
| 片段 / epoch | 围绕事件从长记录截出的一小段。 |
| 事件对齐 / 锁定 | 把每次声音或按键放在相同的零时刻。 |
| 基线 | 用来比较的起始条件或区间；含义随研究问题说明。 |
| 基线校正 | 把指定区间的平均值从片段各点减去的一种处理。 |
| 平均 | 相同时刻的数值相加，再除以记录次数。 |
| 差异波 | 把两组平均相减，查看它们在哪些时候有差别。 |
| 伪迹 | 眨眼、肌肉或接触变化等混入记录的非目标影响。 |
| ERP | 事件相关电位；围绕事件观察的电压变化。 |

## 常见名称背后的问题

| 名称 | 可以先想到的例子 |
|---|---|
| MMN | 一串重复声音中，突然换了一个。 |
| P300 / P3 | 等待的目标终于在候选中出现。 |
| N400 | 一个词与前文的关系，改变了理解过程。 |
| N170 | 比较看到面孔与其他图片后的记录。 |
| CNV / LRP | 等待信号或准备动作时，记录如何变化。 |
| ERN / Pe | 比较自己按错键和按对键之后的过程。 |
| ErrP | 错误相关电位的统称之一；要看具体错误发生在何时。 |
| LPP | 观看不同情绪材料时，一类较晚、持续的变化。 |

这些例子帮助记忆研究情境；实际解释还要连同各章的比较条件。更多名称见 [第五章的卡片](/chapters/eeg/erp-atlas/)。

## 选择与学习

| 词 | 用已经熟悉的事情理解 |
|---|---|
| 脑机接口 / BCI | 把脑活动测量变成可用于交流或控制的信息。 |
| SSVEP | 持续重复的视觉变化，在脑电中带来相应响应。 |
| cVEP | 给目标安排不同的变化顺序，再寻找匹配线索。 |
| RSVP | 让候选在同一位置快速依次出现。 |
| 运动想象 | 手保持不动，在心里想象握拳等动作过程。 |
| 训练与测试 | 先用有答案的记录练习，再用没有参与练习的新记录检验。 |
| 泛化 | 学到的规律换到新记录、新的人或新情境，仍有多大作用。 |
| 数据泄漏 | 测试信息提前进入学习，像考试前已经看过部分答案。 |
| 空闲状态 | 使用者此刻没有打算发出命令。 |
| 神经反馈 | 把一项脑活动测量变成反馈，让人尝试调节。 |
| 共享控制 | 人提供目标，机器承担部分规划或操作细节。 |

## 深入阅读里会遇到的算法名字

以下名称用于查方法，初次阅读主线可以略过。

- **ERD / ERS**：相对基线，某个频率范围的功率下降或上升。先看计算公式的正负约定。
- **CSP**：学习把多个通道怎样组合，能更清楚地区分两类记录。
- **CCA**：寻找两组数据中较相似的变化组合，可用于比较记录与候选节奏。
- **TRF**：描述声音等连续输入，与稍后脑电变化之间的关系。
- **PSD / Welch**：估计不同频率的功率分布；Welch 将短段估计再作平均。
- **STFT**：对一段段短时间分别分析频率，形成随时间变化的图。

这些词的计算细节在对应章节末尾“继续了解”中；解释一个现象时，先说发生了什么、怎样比较，通常更容易让别人跟上。
